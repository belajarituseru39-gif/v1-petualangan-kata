# Petualangan Kata — Pukul Jawaban

Game kuis Bahasa Indonesia SD kelas 1–6 dengan kontrol pukulan telapak lewat kamera.

Versi ini sudah disiapkan untuk GitHub Pages (HTTPS, sehingga kamera diizinkan Chrome).
Berkas `*-local.js` untuk mode `file://` sengaja dihapus agar repo ringan (35 MB).
Untuk pemakaian offline tanpa internet, gunakan paket asli.

## Cara deploy
1. Buat repository baru di GitHub (Public).
2. Unggah ISI folder ini (bukan folder pembungkusnya) ke root repo: `index.html` harus berada di root.
3. Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
4. Tunggu 1–3 menit, lalu buka `https://USERNAME.github.io/NAMA-REPO/`.
